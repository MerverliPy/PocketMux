# UX Map

## Primary flow
1. Open app
2. Select or configure host
3. Connect over SSH
4. Discover or attach remote sessions
5. Present sessions as top tabs
6. Enter active terminal surface
7. Background app
8. Resume and restore usable continuity

## Key screens
- host entry / selection
- connection state
- session tab strip
- active terminal view
- reconnect / recovery state

## UX priorities
- one-handed reachability
- top-level session visibility
- fast switching
- clear reconnect state
- minimal clutter on iPhone
